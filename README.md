# Book Scraper

A small JavaScript web scraper built with **Node.js, Axios, and Cheerio**.

It scrapes book information from [Books to Scrape](https://books.toscrape.com/) and extracts details such as:

- Book title
- Price
- Availability
- Rating

## Tech Stack

- Node.js
- Axios
- Cheerio

## Status

🚧 Work in progress — data cleaning, validation, pagination, and error handling will be added.
